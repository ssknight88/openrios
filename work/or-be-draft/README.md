# OR-BE Draft Workspace

这里保存 OR-BE 尚未成为 golden 的工作产物，包括架构概览、接口材料、模块文档、时序分析和图纸。

目录内的文件可以由人工或 AI 产生，也可以在流程中同时作为输入和输出。它们必须经过评审后，才能晋升到 [`spec/or-be/`](../../spec/or-be/)。

## 内容

- `overview.md`：当前模块和系统概览。
- `architecture/`：架构图和结构草图。
- `interfaces/`：接口规格材料。
- `modules/`：模块级微架构文档。
- `timing/`：时序图、caselist 和 K-map 分析材料。
